# 架构研究决策：不以算子融合替代主方法

日期：2026-09-07。用户明确要求的是架构层面超过 DDTree/DFlash。

## 本轮结论

当前 Protected shared-suffix 方案未达标，保留为失败候选和对照，不进入正式
大规模实验。三条诊断提示的实测为 14.7737 ms/token，DDTree 为 9.2433，
DFlash 为 10.3062；这些不是正式数据集结果，也没有置信区间。
运行记录见 PROTECTED_TREE_BV_RUN_20260907.md。

算子融合探针只有本地未执行代码，没有提交服务器任务。它不是新架构，不能用来
替代用户所要求的算法/网络结构贡献。现有 AdaptiveTree 和 GBV 作业未被修改。

## 已排除的宽泛“创新点”

以下是对论文原文的有限范围核查，不是穷尽文献或优先权证明：

- “给并行草稿加分支条件信息”本身已被
  [JetFlow/JetSpec](https://arxiv.org/abs/2606.18394)、
  [DominoTree](https://arxiv.org/abs/2607.08642) 和
  [DARTree](https://arxiv.org/abs/2608.13524) 覆盖，不能直接当作新贡献。
- “把多分支与多步接受概率一起分配、再按残差纠正”这一宽泛描述已与
  [UniVer](https://arxiv.org/html/2605.04543v1) 及
  [Layer Verification](https://chulheeyun.github.io/publication/cha2026layer/)
  高度重叠。新的具体构造必须指出不同的可计算对象、约束或保证。
- “按验证结果训练草稿”也不是空白：
  [Verification-Aware Training](https://arxiv.org/abs/2608.30135)
  已模拟接受/拒绝并调整训练监督。仅添加接受率辅助损失不足以支持原创性。

## 架构研究必须越过的边界

固定、前缀闭合的候选树 T，若要求条件于 T 后输出仍是 Target 分布，且本轮只能
返回树内前缀加一个纠正 token，则已接受长度期望不超过

    sum_{u in T, u != root} P_target(u).

理由：接受至少 d 个树内 token，要求最终 Target 输出的长度 d 前缀在 T 中；
这些前缀事件互斥。对 d 求和即得界。DDTree 的祖先遍历达到这个界。
这沿用现有 TREE_COUPLING_RESEARCH.md 的分析，不是本轮新定理。

因此，固定树上改变遍历顺序或将逐词操作并成一个函数，不会产生更大的可接受
概率质量。随机树的联合提案分布、输出与树的耦合，或实际可验证条件分布集合
必须发生实质变化。随机树只需积分掉提案随机性后与 Target 一致；不能错误地
将固定树条件界推广成所有随机块验证算法的不可能性定理。

## 下一候选的具体研究对象与验收

研究对象应是**树的联合提案分布与联合块接受规则的共同设计**，而不是目前
“多个根复制同一随机后缀，再修补接受质量”的固定树族。分支应能具有不同的
条件提案，实际生成概率必须可计算；接受深度、分支选择与纠正 token 必须
属于同一归一化联合分布，而不是事后选择最好的分支。

这只是研究规格，目前没有一个已完成的、满足下面条件的新主架构：

1. 明确写出相对 DDTree、DFlash、UniVer/LV 及分支条件草稿工作的实质差异；
   不能只换术语或拼接现有模块。
2. 给出完整序列分布保持的推导，覆盖零提案支持、重复候选、纠正 token、
   EOS、多轮和缓存；先通过独立可穷举 oracle，不将 toy 优势当 GPU 结论。
3. 固定模型、训练数据与算力预算、验证节点预算、数值后端；将架构与实现
   优化分别消融。验证无额外 Target 调用或把这些调用如实计入成本。
4. 在开发状态上证明/实测每轮有效提交增加或目标模型工作量减少，再测总延迟。
   不靠放宽采样、输出长度或更换后端换取“架构加速”。
5. 通过后才冻结以前的数据集选择，进行 DDTree/DFlash 对比、自身消融、
   重复测量、质量检查和置信区间。GH200 与 H200 必须分开标注。

当前没有“保证超过”或“保证顶会原创”的证据。当前失败应驱动架构重设计，
不能通过宣传或只汇报局部 kernel 加速转化为成功。

## 后续实现记录：AC-TBV 原型

用户要求先落地自己的树上块验证后，实现了相关潜变量提案树及映射接受流，
见 [ATOM_TREE_BV.md](ATOM_TREE_BV.md)。它允许各分支后缀不同，保留实际联合
提案概率，并只展开最终选中位置的词表残差。732 项本地测试通过；已接入原
实验流程和三项机制消融。它改变的是推理解码算法结构，不是训练出的新网络。
当前仍未通过 GPU 速度和新颖性门槛，所以上述“没有合格主架构”的判断未被
撤销。旧候选的失败证据保留，官方源码和服务器正在运行的作业未被修改。
