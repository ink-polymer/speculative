# T>0 扩散树块验证：无损与双基线优势的理论审计

日期：2026-09-07。对象：当前 `diffusion_tree_bv`，不是尚未实现的新算法。

后续 [scaffold 改进](DIFFUSION_SCAFFOLD_BV.md) 已另行实现。本审计的纯随机
K3 路径覆盖上界不适用于额外保留确定性路径的新候选树，旧反例不作删除。

结论：在精确算术、正确目标条件分布等明确假设下，完整输出分布无损。
**“对所有目标/扩散分布，都比 DDTree 和 DFlash 好”是假的**，下面给出严格反例。
在一组非平凡的分布条件下，可以严格证明期望接受长度同时超过两者。
这些条件尚未在冻结的 Qwen3/DFlash 权重上验证；本文件没有 GPU 速度结果，
也没有确立新颖性。不能把存在优势的例子写成无条件优势定理。

## 1. 比较对象与无损命题

沿用 [主证明](DIFFUSION_TREE_BV.md) 的记号。固定已提交上下文 c：

    d_j = softmax(z_theta,j(clean-anchor, MASK^L, h(c)) / delta), delta>0;
    Q_D(x_1:L) = product_j d_j(x_j);
    q_j = d_j restricted to S_j, normalized; Q_S = product_j q_j.

这是一次真实 masked-block 去噪后，按位置分类采样的实际提议核。
不把官方 DFlash 的 argmax 路径误写为 Q_D 抽样，也不假设目标分布因子化。
K 条相关路径的每条边缘均为 Q_S；各深度的潜变量独立，标签保留。

令 D 为一轮接受的草稿 token 数，**不含最后一个纠正 token**；一轮未截断
产出为 Y=D+1。令 Z 为本轮结果用目标采样补齐后的序列。无损指

    Pr(Z_1:n=z_1:n | c) = product_i P_T(z_i | c,z_1:i-1)

对每个有限 n 和完整序列成立，不只是每个位置的边缘一致。T>0。
它不是“相同随机种子一定输出同一串”，也不是浮点误差绝对为零。

主证明的充分条件包括：正确的目标 oracle、提议的真实潜变量分布、正确
共享前缀与标签、完整词表纠正分布、精确算术。其关键守恒式是

    w_aj p_aj(x) = R_aj(x) + sum_{h:g_a(h)=x} F_aj(h),
    Q_H(h_1:j+1) w_a,j+1 = Q_H(h_1:j) F_aj(h_{j+1}).

可行性给出非负残差；反向消去未来潜变量后，端点退出质量恰好为
Q_H(h_1:j)R_aj(x)。从公共根 sum alpha=1 开始递归代入，所有路径质量
按目标条件概率分解，得到完整序列定律。给定每个新上下文重复此核，再按
与目标相同的长度上限/EOS 截断，保持同一序列分布。

这部分证明实际使用了块扩散的冻结并行提议 Q_S 和潜变量乘积分布。
其他满足相同因子化假设的非自回归模型也可能适用，因此“用到了扩散模型”
不等于“证明结构只有扩散模型可用”或“此前没人做过”。

本审计的两种基线严格限于项目注册的共享引擎版本：

- DFlash：同一次去噪的 argmax 长度 L 路径，随机目标逐 token matching。
- DDTree：同一去噪位置分布的 product-probability best-first B 节点树，
  按目标条件分布祖先验证；不是对所有官方后端、预算和调参的声明。

给定一个固定且前缀闭合的树 T，DDTree 基线的期望接受数为

    E[D_T] = sum_{v in T, v != root} P_T(v).                    (A1)

证明：D>=d 当且仅当目标 d-token 前缀落在树的第 d 层。层内前缀互斥，
对其目标概率求和，再用 E[D]=sum_d Pr(D>=d)。对固定 DFlash 路径 g，

    E[D_DFlash] = sum_{d=1}^L P_T(g_1:d).                      (A2)

此式是随机 matching，不是通常以 p/q 比例接受的随机草稿 SD。

## 2. 候选树覆盖上界：验证器不能弥补所有提议缺失

定理 A：对于当前 K 条 Q_S 边缘路径构成的随机 trie，任何无损验证器若
只能接受该 trie 中的前缀，对任意固定长度 d 的序列 u，均有

    Pr(D>=d) <= min(1, K Q_S(u) + 1 - P_T(u)).                 (A3)

证明：将事件 D>=d 按 Z_1:d=u 与 Z_1:d!=u 分开。第一部分要求 u 在
候选树内，概率至多 Pr(u in trie)；第二部分概率至多 1-P_T(u)，使用的是
完整输出无损。并集上界给出 Pr(u in trie)<=sum_a Pr(X_a,1:d=u)=K Q_S(u)。
不要求 K 条路径独立，不要求选中的分支与未来潜变量独立。证毕。

选任意固定完整序列 u_1:L，对每个深度应用 (A3)，得到

    E[D] <= sum_{d=1}^L min(1, K Q_S(u_1:d)+1-P_T(u_1:d)).    (A4)

该上界甚至不依赖当前运输公式：只换验证器、不换这类随机候选树，不能
突破它。它不限制采用不同提议、额外目标信息、不同模型或更大预算的方法。

## 3. 严格反例：同一 L=15、K=3、最大 B=45

词表 {0,1}，每个历史处的目标行 p=(99/100,1/100)，每个扩散行
q=(51/100,49/100)，没有支持截断。所有概率严格为正。对任意 T,delta>0，
目标 logits=T log p、去噪 logits=delta log q 实现这些概率，因此反例
不依赖 T=0、无穷 logits、贪心目标或 DFlash argmax 平局。

当前方法取 u=0^15，(A4) 得

    U = sum_{d=1}^15 min(1,3(51/100)^d+1-(99/100)^d)
      = 1864048920924898330259604926727 / 500000000000000000000000000000
      = 3.728097841849796... .                               (A5)

DDTree 有完整的前四层，因为 (51/100)^5 < (49/100)^4：任何五层或
更深前缀的提议概率，小于任何四层前缀。前四层共 2+4+8+16=30 个节点，
故 B=45 至少保证四层，(A1) 给出 E[D_DDTree]>=4>U。
这已经足以证明严格失败，无须依赖同分节点的排序。

当前构树器另外选择 15 个五层节点：一个全 0、五个恰有一个 1、九个
恰有两个 1。没有六层节点，因为 (51/100)^6 < (49/100)^5。因此其精确值为

    E[D_DDTree] = 4 + (.99)^5 + 5(.99)^4(.01) + 9(.99)^3(.01)^2
               = 9999786239/2000000000 = 4.9998931195.
    E[D_DFlash] = sum_{d=1}^15 (.99)^d = 13.854222890512435... .

| 方法 | 同一目标与扩散分布下的 E[D] |
| --- | ---: |
| 当前随机扩散树，任何无损验证器 | <= 3.7280978419 |
| 注册的 DDTree B45 | = 4.9998931195 |
| 注册的 DFlash L15 | = 13.8542228905 |

这是接受长度的严格不等式，不是 GPU 时间的测量。所有方案均在最大节点
预算 45 以内；DFlash 使用 15 个草稿节点。不能称它们实际计算量完全相等。
反例驳倒的是“当前方法总能同时更好”；它不驳倒无损，也不排除其他实例获益。
这是关于上述有限分布模型的定理，不声称冻结 Qwen 权重已经出现此具体实例。

## 4. 可以严格成立的双基线优势

定理 B（非平凡的条件优势）：仍取二元词表、L=15、K=3、最大 B=45。
假设所有扩散槽位 q_j=(1/2,1/2)，无截断；并且给定 c 的每个可能历史上

    0.49 <= P_T(x | c,prefix) <= 0.51, x in {0,1}.           (A6)

目标允许依赖完整前缀，并不要求 iid。当前 full/no-pool 算法均满足

    E[D_full] >= beta = sum_{d=1}^15 (0.98)^d
                     = 12.810113970375209...,
    E[D_DDTree] <= 4 + 15(0.51)^5 = 4.5175378765,
    E[D_DFlash] <= sum_{d=1}^15 (0.51)^d = 1.040773577454077... . (A7)

证明：支持内 p/q>=a=0.98。主证明的保护质量递推为
e_ad/alpha_a=min(1,(e_a,d-1/alpha_a)*(p/q))。由归纳法 e_ad>=alpha_a a^d；
full 的 w_ad>=e_ad。前向质量守恒给出 Pr_full(D>=d)>=a^d，求和得首式。
均匀提议下 DDTree B45 固定包含完整四层与 15 个五层节点；前四层的
目标概率质量各为 1，每个第五层前缀目标概率至多 .51^5，得第二式。
任一 DFlash argmax 平局规则产生的固定路径，其 d-token 前缀概率至多
.51^d，得第三式。12.8101>4.5176>1.0408，优势严格。证毕。

更简单的等分布特例 p=q=(.5,.5)：lift=s，B=C=alpha*s，F=B，所有深度
w=e=alpha，端点 J=15 的概率为 1。因此

    E[D_full] = 15,
    E[D_DDTree] = 4+15/32 = 4.46875,
    E[D_DFlash] = 1-2^-15 = 0.999969482421875.

注意：单路径 BV 在此精确提议情形也全部接受。这不是“树耦合特有增益”
的证据，更不能单凭这个例子证明算法新颖。条件 (A6) 很强且未在真实权重
上认证；它提供确实能证明的存在性/条件结果，而不是对语言模型的预测。

这也不矛盾于 DDTree 在固定提议概率下的构树目标：块验证允许输出与随机
候选树相关；无损约束是对候选随机性积分后的输出律，并不要求给定每棵
候选树后输出仍服从未条件化的 P_T。因此不能把固定树祖先验证公式 (A1)
直接当作随机提议块验证的上界；(A3) 则没有犯这个独立性错误。

更一般的逐上下文证书可用主证明的 A_d：若

    sum_d A_d > max(sum_{v in T_DDTree}P_T(v), sum_d P_T(g_1:d)), (A8)

则 full 对两者的期望接受长度都严格更大。这是可验证的充分条件，不是
所有分布必然满足的事实；一般大词表下精确计算 A_d 需要指数规模信息，
不能当成无需成本的在线自适应选择器。

## 5. 接受长度与实际速度之间还缺什么

一次 draft call 加一次 target call，不意味着各方法每轮成本相等。
候选节点数、attention、全词表归一化、运输、缓存和同步都有成本。
所以 (A7) 本身不能证明真实 GPU 更快。

可以给出一个明确的充分条件，而不是把接受率当吞吐率：设要生成 N 个
token、没有提前 EOS，每轮未截断 Y=D+1<=L+1。假设在**每个**可达历史处，
候选的条件期望产出至少 m_F、每轮期望耗时至多 c_F；基线产出至多 m_B、
每轮耗时至少 c_B。这里每轮耗时包括完整 decode 开销，时间界需硬件证据。

令 R 为到达 N 的轮数，则 R<=N，累计未截断产出在 [N,N+L] 内。
对第 i 轮存在事件 {R>=i}（它只依赖此前历史）使用条件期望，再求和，得

    E[R_F] <= (N+L)/m_F,      E[R_B] >= N/m_B,
    E[time_F] <= c_F(N+L)/m_F, E[time_B] >= c_B N/m_B.        (A9)

故充分条件为 c_F/c_B < (m_F/m_B)*N/(N+L)。不需要独立同分布轮次，
但需要上述对所有历史成立的条件界；共同的 prefill 成本可相消。提前 EOS、
可变草稿长度或不同停止规则需要另行推导，不能直接套用此式。

例如仅在 (A6) 对所有轮次都成立时，(A7) 给出的预期产出比阈值为
m_F/m_DDTree=2.502948648...、m_F/m_DFlash=6.767097596...，有限 N 还需
乘 N/(N+15)。这些数是**每轮成本比的充分阈值，不是测出的加速比**。
本次理论审计既没有建立 GPU 成本界，也没有验证真实模型满足 (A6)。
