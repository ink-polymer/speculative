2026-09-08。**独立研究原型，不是已确认的新论文方法，也不是 GPU 性能结果。**
代码：`src/gbv_experiments/diffusion_core_stopping.py`；精确检验：
`tests/gbv_paper/test_diffusion_core_stopping.py`。
未替换已有 `diffusion_scaffold_*` 注册配置，也未改变它们的主实验结论。

目前可以成立的结论：精确算术下完整序列等分布；固定上下文的 DFlash
接受长度保底；明确分布范围内严格优于项目的 DFlash / DDTree 基线；
修复上一版的两个相反对齐方向的反例。**不能成立的结论：无条件支配 DDTree、

## 1. 扩散核与构造

固定已提交上下文 c，以及 DFlash 一次 clean-anchor + masked-block 去噪的
全部 logits。以下始终条件于这些信息。正目标温度为 T>0，草稿温度为 δ>0。
从去噪输出得到位置分布 d_j，保留支持 S_j 的质量 ρ_j>0，实际采样核为

    q_j(x) = 1{x∈S_j} d_j(x)/ρ_j,
    Q_D(x_1:L) = ∏_j d_j(x_j),   Q(x_1:L) = ∏_j q_j(x_j).

这里的乘积是**一次冻结去噪转换的采样律**，不是将真实目标 AR 条件分布
近似成独立分布。不能直接套用到多次依赖随机中间状态的去噪过程。
代码保留完整的 `DiffusionProposal` 潜变量及 q；K=1，实际原子映射具有
上述乘积 token 边缘。原子标签相同 token 的质量先合并就是 q_j。

设最大深度 L、非根节点预算 B、固定核心预算 M，要求 B≥M+L。

1. 用原始保留质量 d_j=q_jρ_j 的前缀乘积 best-first 构建确定性核心 C_M；
   它复用 DDTree 的构树函数，但仅在保留支持上，不冒充全词表最优树。
2. 令 G 为原始 logits.argmax 的完整 L 长度路径，固定集合 S=C_M∪G。
3. 沿 X~Q 顺序揭示 token。当当前树仍有空位时才揭示下一位，将其前缀加入；
   已有前缀不消耗新节点。空间耗尽或达到 L 就停止，停止深度记为 τ。
   即便下一位可能落在 S 内，空间耗尽后也不再偷看它。若初始无空位则 τ=0。
4. 在 X_1:τ 上使用已有单路径块验证，之后用新鲜的目标随机数在整个树内续接，
   直到输出第一次离开树的纠正 token。所有目标行来自同一棵树的查询。

可一次性采出完整 X 来保存/重放见证，但停止决策不得使用尚未揭示的分量。
也不把 q 换成 `Law(X[:τ] | τ)`，不按 τ 重采样，不挑“看起来最好”的样本。
本构造固定 B，只决定随机路径占用多少节点，不是学习一个最优 GPU 预算。

## 2. 定理：预算停止后的完整序列无偏

“无偏”在这里指对任意有限序列 y，最终生成概率等于目标模型的 AR 概率，
强于仅匹配单 token 边缘或某个评分的期望。假设有限词表、精确实数运算、
正确的目标条件行、正确的 q、独立的新鲜续接随机数。目标概率可以为零，
目标支持不必包含于草稿支持。

### 2.1 为什么这个停止合法

记 ℱ_j=σ(X_1:j)。构树状态只依赖 S 和已揭示前缀，故 {τ≤j}∈ℱ_j。
“是否再抽第 j+1 位”的指示 I_j=1{j<τ} 是 ℱ_j 可测的。
在决定继续时，任一可能的下一位至多消耗一个节点，因此**所有**下一位
都能容纳，不会按即将抽到的值筛选提议分布。

### 2.2 停止流量守恒

在一条实现路径上定义 w_0=1。在深度 j，p_j(x)=P(x|c,X_1:j)，并令

    F_j(x) = I_j min(w_j p_j(x), q_{j+1}(x)),              j<L,
    F_L(x) = 0,
    R_j(x) = w_j p_j(x) − F_j(x),
    w_{j+1} = F_j(X_{j+1}) / q_{j+1}(X_{j+1}).            j<L

分母只在正概率提议样本上计算。q(x)=0 时 F_j(x)=0，不丢弃其目标残差。
停止后所有后续 w 都置零；可将过程补到固定长度 L，这些虚拟行不需要目标查询。
在 τ 处 F_τ=0、R_τ=w_τ p_τ。这正是普通 BV 以 τ 为末端的终止行，
所以补零的固定 L 过程与实现调用的 τ 长度 BV 完全相同。
K=1 时现有运输核的保护量与总分数相同，上式就是它的标量形式。

逐点有 0≤w_j≤1、R_j(x)≥0，且

    w_j p_j(x) = R_j(x) + F_j(x).                         (1)

记 r_j=Σ_x R_j(x)，f_j=1−w_j，t_j=r_j+f_j=1−Σ_x F_j(x)。
由于下一位在继续决策之后仍服从 q_{j+1}，

    E[w_{j+1} | X_1:j] = Σ_x F_j(x).                     (2)

这是证明真正使用冻结块扩散乘积采样的位置。如果按未来样本剪枝，(2) 不再
是对原 q 的条件期望，不能继续使用该证明。

### 2.3 反向选择的关键引理

置 W_{L+1}=1，W_{j+1}=∏_{k=j+1}^L(f_k/t_k)。断言

    E[W_{j+1} | X_1:j] = t_j.                            (3)

基例 j=L：t_L=1。反向归纳时，用下一行的归纳假设，得到

    E[W_{j+1}|X_1:j]
      = E[(f_{j+1}/t_{j+1}) E[W_{j+2}|X_1:j+1] | X_1:j]
      = E[f_{j+1}|X_1:j]
      = 1−Σ_x F_j(x) = t_j.

零分母处理：t_k=0 则 r_k=f_k=0。取 f_k/t_k=0、r_k/t_k=1；上述乘积
恒等式仍满足 `(f/t)*t=f`。同时非负 W_{k+1} 的条件期望为 t_k=0，故它
几乎处处为零；该行的端点概率为零，不会实际抽取无质量的残差。这不依赖
先假定该行不可达来证明它不可达。

给定完整 X，反向核选择端点 j 的概率为

    π_j = (r_j/t_j) W_{j+1},

然后抽 R_j/r_j 作为纠正律。因 `(r/t)+(f/t)=1` 且 f_0=0，Σ_jπ_j=1。
对未来 X 积分，用 (3) 得到前缀 a、端点 j=|a|、纠正 x 的联合质量

    ν_j(ax) = Q(a) R_j(x; a).                            (4)

不是声称给定 τ 或给定随机树时输出已经服从 P。

### 2.4 完整序列证明，不止边缘证明

设 η_j(a)=Q(a)w_j(a)，η_0(空串)=1，η_{L+1}=0。
由 q 的乘积因子、w 更新式及 (1)，即使 q(x)=0 也有

    η_j(a) P(x|c,a) = ν_j(ax) + η_{j+1}(ax).             (5)

固定 y 长度 L+1，将所有可能的端点输出按真实目标条件律补齐：

    Pr(Z=y) = Σ_{j=0}^L ν_j(y_1:j+1) P(y_j+2:L+1|c,y_1:j+1).

将 (5) 代入，η 项逐层望远镜抵消，首项为 P(y|c)，末项为零。
因此 Pr(Z=y)=P(y|c)。这也涵盖所有含零目标概率的序列；不需要除以 P(y)。

最后，在每个实现的 (X,已输出前缀) 上，树内续接使用独立目标条件抽样。
把这段续接在离树处切开，不改变补齐后的完整序列律。积分 X 后仍为 P。
跨轮条件于每轮已提交上下文归纳，得到任意有限输出上限下的目标联合分布；
相同 EOS/长度截断作为确定性映射也保持等分布。证毕。

这是一份普通数学证明及有限精确检验，**不是 Lean/Coq 形式化证书**。
FP64 实现与精确核的误差另以穷举比较，不宣称浮点数实现数学上的零误差。

## 3. 接受长度下界中扩散模型的作用

D 为接受的非根节点数，不含最终纠正；每轮产出 Y=D+1。
记 R_T(Z) 为 Z 在树 T 中的最长前缀。续接后 D=R_T(X)(Z)，S 始终在树内：

    Pr(D≥d) ≥ C_d := Σ_{a∈S, |a|=d} P(a|c).

特别地 C_d≥P(g_1:d|c)，所以固定上下文的 DFlash matching 接受尾概率保底
继续成立；这不是不同上下文、不同运行轨迹的时间比较。

若对所有 X 均有 τ≥m，则对 d≤m，(3) 还给出 BV 原端点尾概率 E[w_d]，即

    A_d = Σ_{a∈V^d} min_{0≤k≤d} [ Q(a_1:k) P(a_k+1:d|c,a_1:k) ],
    Pr(D≥d) ≥ max(C_d, A_d),                             d≤m. (6)

理由：w_d 为沿前缀各段 p/q 乘积与 1 的最小值，乘 Q(a) 后即上式。
在 q 为零的前缀上最小值含 Q(a)=0。续接只增加已接受长度。
对 d>m 不擅自保留未停止 BV 的 A_d 下界。

将实际去噪核代入，p_j/q_{j+1}=ρ_{j+1}p_j/d_{j+1}。
若每个可能历史、每个保留 token 都满足该比值≥κ_{j+1}，0≤κ≤1，则

    A_d ≥ ∏_{i=1}^d κ_i.

所以界依赖**实际块扩散位置分布及保留质量**，不是给 argmax 路径编造 Q。
但这些性质同样适用于其他具有该乘积采样律的非 AR 提议器；
**该证明不足以声称扩散独有的新定理**。训练目标与 KL 的进一步界沿用
[原扩散证明](DIFFUSION_TREE_BV.md)，不重复申报创新。

## 4. 同一 B45/L15 的有条件双基线优势

这里 DDTree 是项目的乘积 best-first B45 + 目标祖先采样；DFlash 是完整
argmax L15 + 随机 matching。不是对论文中所有预算/变体的比较。
基线 DDTree 与本构造都最多查询 45 个非根节点，根行另计；DFlash 只查询
15 个，所以接受数的优势不自动抵消其更低的查询成本。

考虑无支持截断的二元词表，每位置 q_j 的两个概率都在 [.49,.51]，
目标 P 在**每个历史**的两个条件概率也都在 [.49,.51]；允许任意 AR 依赖。
正温度下可用 logits=T log p、δ log q 实现，不只是一个 p=q 点。

由于 .51^5<.49^4、.51^6<.49^5，DDTree 前 30 个节点必为完整四层，
B45 必为这四层及 15 个第五层节点。M30 核与完整 G 联合只有 41 个节点，
剩余四个位置。任意随机路径的前四层免费，再差也能容纳四位，所以 τ≥8。
令 r=49/51，(6) 给出

    E[D_new] ≥ 4 + Σ_{d=5}^8 r^d = 7.087185165863393...,
    E[D_DDTree] ≤ 4 + 15(.51)^5 = 4.5175378765,
    E[D_DFlash] ≤ Σ_{d=1}^15(.51)^d = 1.0407735774540776....

这是明确条件下的严格理论分离，不是对 Qwen 固定模型已经成立的证书。
任何真实词表中的二元近似都不能直接替代这里的完整二元分布假设。

### 两个旧反例的修复

继续固定 q=(.51,.49)、L15/B45/M30。用同一目标，不修改预算：

| 目标每行 | 新方法可证明下界 | 推导 |
|---|---:|---|
| p=(.99,.01) | 13.953227880512436 | 完整四层 + G 的第 5..15 层 |
| p=(.001,.999) | 4.05219433588645 | 完整四层 + A_5..A_8 中全 1 路径的贡献 |

精确有理数计算表明这两项均严格大于对应 DDTree 和 DFlash 的期望接受数。
第二项只取贡献 q(1)^d，是因为全 1 路径上所有 p/q>1。
先前的随机完整路径优先版本在第二项有 3.2270665892824146 的上界。

### 仍然不能保证普遍胜过 DDTree

新构造自身也有 **L15/B45/M30 的严格正概率反例**：q=(.51,.49)，
目标每一步以 .999 概率选择序列 u=000010000000000 对应位置的 token，
以 .001 选择另一个。DDTree 必含 u 的前五个前缀。

新树只在随机路径匹配时包含 u_1:d（5≤d≤8），其概率为 .51^(d−1)*.49。
第 5 位起均不在核心或 G 内，四个新节点后 τ=8，所以深度 ≥9 的 u 前缀
绝不在新树内。对任何无损耦合，不假设树与 Z 独立，有

    Pr(D≥d) ≤ Pr(u_1:d∈T) + 1−P(u_1:d).

从而

    E[D_new] ≤ 4 + Σ_{d=5}^8 .51^(d−1)*.49
                 + Σ_{d=5}^15 (1−.999^d)
              = 4.172527026183957...,
    E[D_DDTree] ≥ Σ_{d=1}^5 .999^d = 4.985019985005999.

测试穷举所有 2^15 个完整草稿验证覆盖关系，再用 Fraction 证明严格差距。
因此修复两个旧例子不等于解决所有反例；不能隐去这一项只报告有利分布。

### 如何转成时间条件

上述邻域下的每轮产出下界为 8.087...，DDTree 上界为 5.517...。
若每个上下文都符合这些假设，且每轮成本有相应一致上下界，则新方法成本
与 DDTree 成本之比小于 1.4657235431600564 时，满足无限长度的充分比较条件。

## 5. 新颖性审计：当前不能保证不重复

检索日期 2026-09-08。下面比较实际机制，不以名称不同作为新颖性证据。

| 已有工作与一手来源 | 明确重合 | 本原型的剩余差别及判定 |
|---|---|---|
| [Block Verification](https://arxiv.org/html/2403.10444) | 单路径联合端点/纠正及分数递推 | 沿用其 K1 核；不是新验证算法 |
| [Layer Verification，作者页](https://chulheeyun.github.io/publication/cha2026layer/) | 单步无损规则提升到树，层间协调与反向选点 | 现有运输实现来自此类框架；本次完整 PDF 受 OpenReview 验证页阻挡，不声称已逐条排除其全部定理 |
| [UniVer](https://arxiv.org/html/2605.04543) | 条件运输、前缀质量、局部到整体无损定理，含确定候选与随机候选组合 | 停止流量证明属于相近守恒框架；未证明存在无法归约的新机制 |
| [DDTree](https://arxiv.org/html/2604.12989) | 冻结块扩散位置乘积、best-first 树 | 核心直接复用它，不申报为创新 |
| [BASTION](https://arxiv.org/html/2605.29727) | 块扩散树、路径质量代理与预算/成本联合考虑 | 此处是固定预算下停止随机 BV 前缀，不是它的成本控制器；仅此差别不足以确认论文创新 |
| [CaDDTree](https://arxiv.org/html/2606.01813) | 扩散树结构和节点预算优化、带成本的停止规则 | 本原型没有它的吞吐最优预算结论；不能声称首次预算自适应 |
| [SpecDec++](https://arxiv.org/html/2405.19715) | 自适应候选长度与停止决策 | 判据是重叠节点预算而非训练的接受预测，但“动态长度”不是新概念 |

这些来源分别覆盖验证核、扩散提议、确定/随机候选混合和长度/预算选择。
因此“扩散 + 树 + 块验证 + 自适应停止”**不能直接作为原创性声明**。
本轮证明的可预测停止与覆盖下界更保守地定位为组合方法的正确性推论和
反例分析；尚未找到足以确认独立新贡献的、不可归约的部分。
检索未命中一个完全相同的名字，也不能证明没有相同方法。

如果后续要作为论文主贡献，需要新增已有框架不能直接推出的机制/定理，
并与其明确假设逐项比较。当前状态必须保留 `novelty_established=False`；
没有把“查过文献”当成“不重复”的保证。
