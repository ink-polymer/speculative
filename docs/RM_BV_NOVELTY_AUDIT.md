# RM-BV 原创性核查：机制而非名称

核查日期：2026-09-07。对象：当前 `root_marginalized_bv.py`。
范围：公开论文的算法、公式和适用条件；不是“全世界无人做过”的证明或录用保证。
本轮没有修改推理算法，也没有 GPU 性能结果。

后续三轮反向检查见 [RM_BV_THREE_PASS_RECHECK.md](RM_BV_THREE_PASS_RECHECK.md)：
新增独立有理数 oracle，发现 RM-BV 在两步实例上可输给同树 early-root BV；
53 项新增审计和 609 项完整回归通过。该反例进一步限制多步收益主张。

## 结论

**“新的树上块验证通用框架”这一宽泛主张不成立。** 当前 RM-BV 的后向阶段
可以用 Layer Verification（LV）的概率流公式表达；改抽样顺序不能单独作为创新。

**仍有具体差异可研究：面向并行位置 proposal 的共享后缀构造，以及跨根共享
proposal 质量的前向流分配。** 它与 LV §4.2 的标准节点局部源容量分配不同。
该区别不等于已经确认原创，更不等于达到顶会标准；需要完成最近邻全文核查和实测。

## 2. 新发现：后向阶段的代数归约

下面是本轮自己的代数推导，不是声称 LV 原文已经写出 RM-BV。
先条件于根落在预选集合 S 内。沿已采样的共同后缀，在深度 i 记：

    α_a = 当前根后验；p_a(x) = 对应 Target 分支的下一词概率
    M(x) = Σ_a α_a p_a(x)；Q(x) = 共享后缀的真实 proposal 条件
    w = 当前 BV 前缀权重；a_a = w α_a

构造前向流：

    F_a(x) = [α_a p_a(x) / M(x)] min{w M(x), Q(x)}.

M(x)=0 时定义 F_a(x)=0。它满足

    F_a(x) ≤ a_a p_a(x),
    Σ_a F_a(x) ≤ Q(x).

对实际采样 token z，有

    F_a(z)/Q(z) = w_next α_next(a).

令 R(x)=[w M(x)−Q(x)]_+，则该节点的目标剩余流为

    a_a p_a(x)−F_a(x) = [α_a p_a(x)/M(x)] R(x).

将其代入 LV §4.1 的端点概率与 residual 公式，端点 a 和 correction x 的
联合行概率为上述剩余流除以 `1−Σ_a,x F_a(x)`；分母等于 `1−w+Σ_x R(x)`。
这恰好等于 RM-BV 的该行 BV 成功概率、correction 抽样与根后验恢复的乘积。
从深到浅的失败概率连乘也相同。最后一层取 Q=0；零分母的不可达阶段任意补全。
集合 S 外的 Target 首词回退另按入口质量处理。

本轮以固定 seed 20260907 检查了 200 组随机 FP64 概率实例，每组 K=3、15 层、
词表 17：容量约束、下一层分数以及联合行概率的上述恒等式均通过；最大联合行
误差约 3.33e−16。这是代数核查，不是文献原创性证明，也不是 GPU 基准。

**归约的边界：等价于 LV 后向公式的一种流实例，不等价于 LV 原论文的标准前向算法；
不能因此断言整个方法已重复，也不能继续把后向层采样宣称为原创。**

## 3. 剩余差异：分摊源容量 vs 共享源容量

LV §4.2 的标准构造取 `λ_a=a_a/Σ_a a_a=α_a`，对应节点局部源容量 `α_a Q(x)`。
上述 F_a 只要求跨根总量不超过 Q(x)，不要求每个 F_a 都不超过 α_a Q(x)。
共享后缀的随机事件只有一份，因此可在看到后缀 token 后联合分配这份质量。

最小数值见证：w=1，α=(0.5,0.5)，Q=(0.5,0.5)，两根 Target 条件分别为
(0.9,0.1)、(0.1,0.9)。共享方案的流矩阵为

    [[0.45, 0.05],
     [0.05, 0.45]],

局部源容量矩阵则每项为 0.25。前者总匹配流为 1；受后者源容量和相同 Target
容量共同限制的最大流总量为 0.6。两者前向规则确有区别。
这是同一层容量问题的数学例子，不是原版 LV 整系统基准，也不是 1/0.6 倍 GPU 加速。

共享源容量下，该层总流上界为 `Σ_x min{w M(x), Q(x)}`，上述 F 达到该值。
这个局部最大流结果是基础耦合/容量论证，不能单独包装成新的顶会主定理；
它也不证明全树期望接受长度全局最优。

## 4. 扩散结合怎样才形成有分量的贡献

候选贡献应收窄为：利用 DFlash 式一次前向暴露的位置 proposal，设计相关候选树，
并给出无需额外 Target 前向、可精确执行的跨根前向流构造。
不声称只适用于扩散模型；其他能提供相同概率接口的并行 drafter 也可能适用。

达到论文主方法标准还需要：

1. 针对 LV 标准前向、UniVer 和最近的 diffusion-drafter 方法，明确证明不是已有算法的直接替换参数；允许并诚实说明其在通用框架内的关系。
2. 不止一个人工复制/奇偶分布：给出多步收益条件、失败区域及计算代价分析。原先对固定树 DDTree 的分离不足以代表对所有树验证器的分离。
3. 在相同模型、真实 GPU、原数据协议下完成端到端比较。DDTree/DFlash 是必要对照；LV/UniVer 或不可运行原因也需交代。
4. 用同树分布的机制消融和单独同状态重放，区分共享 proposal、跨根分配、BV 与实现优化的贡献。训练或调参不能泄漏正式测试集。

## 5. 证据完整性与限制

UniVer 的算法 1、式(3)–(7)已核对公开 PDF 第 4–5 页原图。
GBV、DBLast、DDTree 等使用公开 arXiv 正文核对。
LV 的作者页面、公开索引中的 §4.1–4.2 与附录 F.1 公式已取得，但其
[完整 PDF](https://openreview.net/pdf/861a0763f6dd43acb432b81a5145443a8b0eeb1b.pdf)
直接访问仍被浏览器验证阻挡；未绕过验证，未声称完成全部附录的审阅。
上述对 LV 的归约是基于已取得公式的明确推导；最终相关随机树适用范围仍须全文复核。

检索包含 root/target marginalization、shared suffix、posterior、Rao–Blackwell、
correlated diffusion drafts、layer verification 等机制词；未找到同名或相同描述不是原创证书。

最终判断：**有可明确定位的前向构造差异；通用框架级新颖性不通过；
“原创且顶会级”目前尚不能标记为已验证。**
