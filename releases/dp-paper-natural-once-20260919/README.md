# Natural-task dual-H20 experiment release

This directory preserves the frozen source code and the complete raw results used for the Qwen3-4B and Qwen3-8B natural-task study completed on 2026-09-19.

## Contents

- `code/`: exact readable source snapshot copied from the H20 runner after completion. Generated bytecode and pytest caches are omitted.
- `raw/qwen3_4b/` and `raw/qwen3_8b/`: lossless `tar.gz` archives of every final result phase, model-level logs and metadata, nonformal smoke artifacts, and generated top-level reports. Their `supporting-history/` directories preserve the earlier cache, preflight, memory-safe, single-wave, and study runs found on each server.
- `dp-paper-natural-suite-20260917/`: readable predecessor source snapshot required by the frozen protocol-comparison tests; its original archive is also retained under each server's supporting history.
- `summaries/`: directly readable aggregate cells, paper tables, experiment plans, and quality reports extracted from the raw archives.
- `FINAL_STATUS.md` and `FINAL_STATUS.json`: concise final audit and machine-readable findings.
- `MANIFEST.json`: SHA-256 and byte size for every released file.

The final uncompressed raw results contain 42,198 files and occupy about 1.78 GB. Supporting history adds roughly 650 MB of earlier code and results. The data are split by server and phase so every Git object remains below GitHub's 100 MB per-file limit. No measurement records in the included experiment directories were discarded. A directory explicitly named `dp-unrelated-archive-20260916` and a reproducible Hugging Face download cache were excluded.

## Completed protocol

Each model completed 10,788 request groups and 53,280 method executions across `main128`, `quality`, `correctness`, `native_c1`, `budget`, `ablation`, and `heterogeneous`. The separate long-output performance phase was intentionally removed at the user's request and is recorded in `code/effective_queue.json`.

The queues finished successfully at 2026-09-19 05:46 Beijing for Qwen3-4B and 05:50 for Qwen3-8B. No `FAILED_PHASES` entries were present. The exact source hashes embedded in both models' completion records match the files in `code/`.

## Verify and extract

From either raw model directory:

```bash
sha256sum -c SHA256SUMS
mkdir extracted
for archive in *.tar.gz; do
  tar -xzf "$archive" -C extracted
done
```

On macOS, use `shasum -a 256 -c SHA256SUMS` if `sha256sum` is unavailable.

## Evidence limits

- Main-stage DP/AR throughput speedups range from 1.737x to 4.734x on the tested cells.
- DP beats the adapted DFlash implementation in all 24 capacity-feasible main cells, but it does not consistently beat DDTree.
- Native C=1 DP is 7-10% slower than native DDTree.
- Full DP is not the raw-throughput winner in the 16 ablation cells; simpler variants are up to 4.96% faster.
- Quality noninferiority versus AR is supported in 5 of 8 model-dataset cells. Qwen3-4B MBPP is 2.03 percentage points below AR.
- Strict BF16 sequence-law equality is not certified.

See `FINAL_STATUS.md` for the compact audit and `summaries/*/OBSERVED_CELLS.json` for aggregate measurements.
